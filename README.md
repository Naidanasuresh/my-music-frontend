# 🎧 VibeTune - Music Frontend

A modern, responsive music streaming interface built with vanilla JavaScript, HTML, and CSS. VibeTune is a mood-based music discovery platform that lets users browse and play music organized by emotional categories.

## ✨ Features

- **Mood-Based Music Discovery**: Browse songs categorized by emotions
  - 💔 Heart Break
  - 💕 Love
  - 🔥 Motivation
  - 🎵 Telugu Songs
  
- **Interactive Sidebar Navigation**: Easy access to Home and Playlists
- **Video Carousel**: Navigate through promotional music videos with previous/next buttons
- **Song Player**: Built-in music player with playback controls
  - Play/Pause button
  - Previous/Next track navigation
  - Song information display with poster images

- **Responsive Design**: Works seamlessly across different screen sizes
- **User-Friendly UI**: Clean and intuitive interface with emoji-based branding

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Build Tool**: Vite
- **Module Type**: ES Modules
